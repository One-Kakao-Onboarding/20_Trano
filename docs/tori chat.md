[페이지 구현]
챗봇 화면에서 구현되는 추가 화면이야.

원래 있는 챗봇 화면에서 아무 곳이나 클릭하면 "발달장애인 부모"의 장애 정도를 판단하는 설문조사를 진행할거야. 질문은 4개이고 각 질문은 o 또는 x 를 클릭해서 답할 수 있어.

화면의 구성은 상단에 토리 얼굴이 있고 아래쪽에 말풍선이 있고 질문 텍스트가 들어가. 가운데에는 각 질문에 맞는 토리의 상황 사진을 첨부하고
아래쪽에는 왼쪽에 x 버튼, 오른쪽에 o 버튼을 배치해줘

아래는 4개의 질문과 각 질문에 첨부되어야 될 사진의 파일 명이야. 위에 설명한대로 4개의 질문이 뜨고 o, x를 누르면 다음 질문으로 넘어가게 해주고, 마지막 질문이 끝나면 결과 집게 화면을 보여줘
